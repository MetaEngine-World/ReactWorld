The idea

Model the
response.

Embodied video models need to predict how objects respond to a robot’s actions. These responses are often local, brief, and critical to the task: a cloth corner lifts before the rest unfolds, and an indirectly affected object responds differently from the manipulation target.

ReactWorld structures this process into interaction roles, future response strength, and interval motion. A response feedback adapter uses these predictions to update object features relative to a zero-dynamics reference and to guide temporal attention with displacement.

Read the project abstract

ReactWorld anticipates structured interaction responses from the video generator’s intermediate features within each denoising forward pass. The interaction response field predictor describes participant roles, future motion response strength, motion support, and displacement. The response feedback adapter constructs dynamics-dependent object increments by subtracting a zero-dynamics reference, and turns predicted displacement into a positional bias for temporal attention. Experiments in the current manuscript report a RBench average of 77.51, together with EZS-Bench Domain and average scores of 86.98 and 81.87.

03 / METHOD

ReactWorld overview. Within one DiT forward pass, the interaction response field predictor supplies context and dynamics to the response feedback adapter. Role-conditioned feature updates are applied first, followed by displacement-guided temporal attention over the updated features.

05 / EVALUATION

Task-aware object responses

In the current RBench table, ReactWorld improves all five task-category scores over PhysisForcing. The complete table also reports results for four robot embodiments.

Response feedback contributes

Adding prediction heads alone is less effective than feeding the predicted responses back into generation. The full model also improves over the variant without displacement bias.
